# Работа с таск-менеджером

Сайт — https://tasks.molotilka.site. Бот — https://t.me/bnb_tasks_manager_bot.

## Первый вход Ильи

Telegram ID 1287414278 имеет роль администратора. Откройте бота, отправьте /start и нажмите кнопку меню «Задачи». Mini App использует ваш связанный профиль.

### Что делать после Launch

Launch открывает таск-менеджер внутри Telegram. Вход выполняется автоматически: отдельный логин, пароль и повторная привязка Telegram здесь не нужны.

1. На экране «Мои задачи» нажмите карточку задачи. Для текущей тестовой задачи №4 это «Тестовая задача».
2. Нажмите «Начать работу», затем «Добавить результат».
3. Введите текст результата или выберите файл и нажмите «Отправить».
4. Задача перейдёт на проверку. Администратор открывает её в «Все задачи» и нажимает «Подтвердить» либо «Вернуть в работу» с причиной.

Чтобы начать реальную работу, откройте «Проекты», затем создайте задачу кнопкой «Создать задачу»: выберите проект, исполнителей и срок. Участников можно добавить через раздел «Участники».

Если закрыли окно, вернитесь в чат @bnb_tasks_manager_bot и нажмите «Задачи» слева от поля сообщения. Если вместо списка задач показана форма входа, закройте Mini App и снова откройте его этой кнопкой.

### Вход в обычном браузере

Для входа на сайт по паролю откройте в Mini App «Участники», найдите свой профиль и нажмите «Выдать вход». Назначьте логин латиницей и скопируйте одноразовый код и его тип. На сайте выберите «Установить пароль по коду», укажите код, тип и новый пароль от 12 символов. После сохранения войдите с этим логином и паролем.

## Добавление участника

В «Участниках» администратор добавляет имя, затем выдаёт логин и код установки пароля. Участник устанавливает пароль на сайте. После входа кнопка «Привязать Telegram» выдаёт команду /link с кодом на 15 минут. Команду нужно отправить боту из своего аккаунта. Далее бот и сайт открывают один профиль.

Повторная выдача входа формирует код восстановления пароля. Роль и активность меняются в разделе «Участники». Перед понижением назначенного ответственного администратора переназначьте его задачи и проекты.

## Задача

Выберите проект, название, описание, флаги, дедлайн и исполнителей. Сохраните форму. Все назначенные исполнители видят общую задачу, статус и результат. Любой текущий исполнитель может начать работу и отправить результат.

Для сдачи откройте «Добавить результат» и отправьте текст, ссылку, документ или фотографию до 10 МБ. На сайте доступна подпись к файлу. Результат переходит на проверку. Администратор подтверждает его либо возвращает в работу с обязательной причиной. При новой сдаче сохраняется отдельная версия результата.

В «Истории» сайта видны изменения. Вложения скачиваются из карточки с проверкой текущего доступа. При исключении из исполнителей обычный пользователь теряет доступ, включая авторский профиль.

Если карточка изменилась параллельно, откройте её заново. Незавершённая форма бота восстанавливается после /start в течение семи дней с последнего изменения.

## Проекты и ответственные

Администратор создаёт проекты и назначает ответственных. Их состав копируется в новые задачи. Ответственных конкретной задачи можно изменить отдельно. Проект с задачами архивируется, задачи сохраняются.

## Сроки

Общий часовой пояс — Москва. Дедлайн указывается датой. С начала следующего дня задача считается просроченной. После 09:00 бот отправляет напоминания на сегодня и ежедневную сводку просроченных. Завершённые и отменённые задачи исключаются. После блокировки бота восстановите доставку командой /start.

## Эксплуатация

Сервис работает на VPS и продолжает работу после выключения Mac. Резервные копии создаются ежедневно около 06:00 Москвы. Инструкция администратора сервера находится в deploy/RESTORE.md. Срок хранения, постоянное внешнее хранилище и целевое время восстановления ожидают согласования.

## Проекты и обновляемая работа

Проект создаёт администратор. В Projects есть разделы Shared projects и Personal projects. Личный проект видят создатель, назначенные исполнители и ответственные администраторы. Исполнитель видит свои задачи внутри проекта. Видимость меняется через Visibility. Существующие проекты первоначально относятся к общим.

При создании задачи с Duration → Recurring она сразу получает статус Recurring. Раздел Working materials позволяет сохранять ссылки с названиями, добавлять, заменять и удалять их. Эти материалы доступны независимо от отправки результата на проверку.

После Approve update обновляемая задача возвращается в Recurring. Администратор завершает её кнопкой Finish recurring task. Рабочие ссылки сохраняются и у завершённой задачи.

## Участники личного проекта

У проекта один ответственный администратор. В Projects → Personal projects → Add members администратор отмечает людей, которым проект должен быть доступен до назначения задач. При создании личного проекта список участников можно заполнить сразу. В существующем проекте можно добавлять участников. Уже назначенные остаются в проекте. В карточке проекта показываются администратор и выбранные участники.

Назначенные участники видят проект и свои задачи внутри него. Создатель и ответственный администратор также имеют доступ. Замена администратора выполняется через Administrator. Исполнитель задачи продолжает видеть её проект по назначению, даже если снята отдельная отметка Project members.
